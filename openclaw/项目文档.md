# AI智能教育在线平台（TJXT）—— 全栈教育平台项目文档

---

## 一、项目概述

**项目名称：** AI智能教育在线平台（Tianji Education AI / TJXT）

**项目定位：** 一个集在线课程学习、互动问答、积分激励、AI 智能助教、考试测评于一体的综合性在线教育平台。采用微服务架构设计，支持高并发场景，提供完整的从前端到后端的全链路解决方案。

**开发语言：** Java 17

**架构风格：** 微服务架构（Spring Cloud Alibaba）

## 四、功能模块详解

### 4.1 用户与认证（tj-auth + tj-user）

- **用户管理：** 学生、教师、管理员多角色体系
- **认证授权：** 基于 JWT 的登录拦截，Spring Cloud Gateway 统一鉴权
- **用户资料：** 头像、昵称、个人信息管理

### 4.2 课程管理（tj-course）

- **课程 CRUD：** 课程基本信息、分类管理、教师分配
- **课程目录管理：** 多级目录结构（章节 → 小节）
- **草稿机制：** `CourseDraft` + `CatalogueDraft` 独立的草稿发布流程
  - 课程信息草稿（CourseDraftServiceImpl，约 30890 行）
  - 目录草稿（CourseCatalogueDraftServiceImpl，约 37288 行）
  - 教师分配草稿（CourseTeacherDraftServiceImpl）
- **分类体系：** `CategoryServiceImpl`（约 28561 行）支持多级课程分类管理

### 4.3 交易与购物车（tj-trade）

- **购物车：** 商品添加、删除、数量调整
- **订单管理：** 下单、订单详情、订单状态流转
- **支付对接：** 支付宝 SDK 集成，支付回调处理
- **退款管理：** 退款申请、退款审核、退款状态追踪

### 4.4 支付服务（tj-pay）

- 独立的支付微服务，支持支付渠道对接
- 支付回调处理、退款处理

### 4.5 促销与优惠券（tj-promotion）⭐ 核心亮点

- **优惠券管理：** 优惠券创建、发放、核销、退款
- **优惠券类型：**
  - 无门槛券（NoThresholdDiscount）
  - 每满减券（PerPriceDiscount）
  - 折扣券（RateDiscount）
  - 满减券（PriceDiscount）
  - 基于策略模式（DiscountStrategy + EnumMap）
- **兑换码系统：**
  - **高性能兑换码生成算法：** 支持 20 亿级别兑换码，通过 Redis 自增序列号 + 自定义编码算法（CodeUtil.generateCode），兑换码可脱离数据库做高效校验
  - **Bitmap 判重：** 使用 Redis Bitmap（SETBIT）实现 O(1) 的兑换码判重，单 key 支持 20 亿位
  - **ZSet 范围查询：** 借助 Redis ZSet 存储兑换码与优惠券的映射关系，通过 rangeByScore 快速定位兑换码对应的优惠券
- **领券并发控制：**
  - 使用 **Lua 脚本**（receive_coupon.lua / exchange_coupon.lua）保证领券和兑换操作的原子性
  - Redis Hash 缓存优惠券信息，减少数据库查询
  - RabbitMQ 异步落库
- **优惠券叠加推荐算法：**
  - 基于**排列组合 + 异步计算**（CompletableFuture + CountDownLatch）
  - 细筛可用券 → 排列组合（PermuteUtil，回溯算法）→ 并行计算各方案优惠金额 → 筛选最优解（优惠最大 + 用券最少）

### 4.6 学习服务（tj-learning）⭐ 核心亮点

- **课表系统：** 用户购课后自动生成课表，学习进度跟踪
- **学习记录：**
  - **Redis + DelayQueue 异步落库方案：** 播放进度采用 Redis 缓存 + JVM 延迟队列（DelayQueue），每 20 秒异步写入一次数据库，误差 < 15 秒，DB 写压力大幅降低
- **签到模块：**
  - 使用 **Redis Bitmap** 实现签到记录，按年月生成 key，offset 为日期
  - 位运算计算连续签到天数（`(num & 1) == 1` → 右移继续检查）
  - 签到积分：连续 7 天 +10 分，14 天 +20 分，28 天 +40 分
  - 存储空间相比传统方案节省 80%
- **实时积分排行榜（学霸天梯榜）：**
  - 基于 **Redis ZSet** 的实时排名，按月分 key
  - 当前赛季走 Redis 查询（reverseRangeWithScores）
  - 历史赛季走 MySQL（动态表名，按赛季分表）
  - **XXL-Job 分片任务**定期将 Redis 数据持久化至 MySQL
- **互动问答：** 课程问答、回复、笔记
- **AI 助教集成：** 学习过程中调用 AI 助手解答问题

### 4.6.1 互动问答与笔记

- **课程问答：** 用户可针对课程小节发起提问，支持回复、采纳、置顶等管理功能
- **笔记：** 支持用户在学习过程中记笔记、管理笔记、公开/私密控制

### 4.7 评论与点赞（tj-remark）

- 点赞记录与管理（LikedRecordController）
- 基于 RabbitMQ 异步解耦

### 4.8 搜索服务（tj-search）

- **课程全文搜索：** ElasticSearch 实现课程内容的全文检索
- **兴趣推荐：** 基于用户兴趣标签的个性化推荐
- **热门推荐：** 热门课程推荐

### 4.9 媒资管理（tj-media）

- **图片管理：** 上传、展示（支持阿里云 OSS / 腾讯云 COS）
- **视频管理：** 腾讯云 VOD 点播集成

### 4.10 考试测评（tj-exam）

- **题目管理：** 题库管理，增删改查
- **试题关联：** 题目与业务场景关联（QuestionBizController）

### 4.11 消息通知（tj-message）

- 短信通知（腾讯云 SMS）
- 系统消息通知

### 4.12 AI 智能助手（tj-aigc）⭐ 亮点

- **多种智能体架构：**

  | 模式 | 实现 | 说明 |
  |------|------|------|
  | 增强型智能体（ENHANCE） | ChatServiceImpl | RAG + Chat Memory，直接问答 |
  | 路由工作流智能体 | RouteAgent | 意图识别 + 分发到子智能体 |
  | 推荐智能体 | RecommendAgent | 课程推荐 |
  | 购买智能体 | BuyAgent | 下单购买流程 |
  | 课程智能体 | CourseAgent | 课程信息查询 |
  | 知识库智能体 | KnowledgeAgent | RAG 知识库问答 |

- **RAG 检索增强生成：**
  - 使用 Spring AI 集成 DashScope 大模型 + text-embedding-v3 文本向量化
  - ElasticSearch / Redis-Stack 作为向量存储
  - 相似度阈值 0.6，topK=5
- **工具调用（Function Calling）：**
  - CourseTools：课程查询
  - OrderTools：预下单操作
- **会话管理：** Redis 实现 ChatMemory，支持多轮对话
- **流式输出：** 基于 WebFlux 的 SSE（Server-Sent Events）实时推送
- **停止生成：** 支持用户手动停止 AI 输出

### 4.13 数据统计（tj-data）

- 学习数据统计与分析

## 五、架构设计要点

### 5.1 分布式配置

- 所有微服务通过 Nacos 管理配置
- 共享配置：shared-spring.yaml（Spring 通用）、shared-logs.yaml（日志）、shared-feign.yaml（Feign）、shared-mybatis.yaml（MyBatis）、shared-redis.yaml（Redis）

### 5.2 API 文档

- 各服务独立集成 Knife4j（Swagger），可通过网关统一访问
- API 前缀由网关做 StripPrefix=1 路由处理

### 5.3 跨域处理

- Gateway 全局 CORS 配置，支持跨域请求

### 5.4 消息队列

- RabbitMQ 实现异步解耦
- 应用场景：
  - 优惠券领取 → 异步落库
  - 点赞/评论 → 异步统计
  - 签到 → 积分异步处理
  - 学习进度 → 异步持久化

### 5.5 安全与拦截

- 自定义 `@Auth` 注解 + 登录拦截器
- 资源级别权限控制（`tj.auth.resource.enable`）

## 七、性能优化与高并发设计

| 场景 | 方案 | 效果 |
|------|------|------|
| 领券高并发 | Lua 脚本保证原子性 + Redis Hash 缓存 + MQ 异步 | 避免超发，提升 TPS |

| 点赞/评论 | RabbitMQ 异步解耦 | 提升系统吞吐量 |
| 课程搜索 | ElasticSearch 全文检索 | 毫秒级搜索响应 |
| 优惠券方案推荐 | 回溯算法排列组合 + CompletableFuture 并行计算 | 保障结算速度 |

## 九、项目亮点总结

1. **全微服务架构：** 16 个微服务模块，涵盖在线教育完整业务链路
