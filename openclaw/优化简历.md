## 项目经历

### AI智能教育在线平台 | 后端开发 | 2026.01 - 2026.02

**技术栈：** Spring Boot 3.x / Spring Cloud 2023 + Alibaba / Nacos / Redis / RabbitMQ / MySQL / ElasticSearch / XXL-Job / Spring AI / MyBatis-Plus

**项目描述：** 一个集在线课程学习、互动问答、积分激励、AI 智能助教于一体的综合性在线教育平台。采用微服务架构，拆分为 16 个微服务模块，涵盖课程管理、交易支付、用户学习、促销优惠、搜索推荐、考试测评等完整业务链路。针对领券、签到、排行榜等高并发场景进行了深度架构优化。

**核心职责与成就：**

**1. 优惠券系统设计与开发**
- **高性能兑换码生成：** 设计了一套支持 20 亿量级的兑换码生成算法，基于 Redis 自增序列号 + 自定义编码（CodeUtil），实现兑换码的生成、校验、解析全流程。兑换码可脱离数据库做高效校验
- **Bitmap 判重：** 采用 Redis Bitmap 实现 O(1) 级别的兑换码已兑判重，单 key 支持 20 亿位空间，无需查表
- **ZSet 映射查询：** 利用 Redis ZSet（rangeByScore）快速定位兑换码对应的优惠券，避免数据库查询
- **并发安全领券：** 通过 Lua 脚本保证领券和兑换操作的原子性，结合 Redis Hash 缓存优惠券信息 + RabbitMQ 异步落库，解决高并发超发问题
- **优惠券叠加推荐算法：** 基于排列组合（回溯算法 + CompletableFuture 并行计算）枚举所有用券方案，综合"优惠金额最大"和"用券数量最少"两个维度筛选最优解，支持多类型折扣策略（无门槛/每满减/折扣/满减）

**2. 学习进度处理优化**
- 设计并实现"**Redis 缓存 + DelayQueue 延迟队列异步落库**"方案处理视频播放进度。播放过程中实时更新 Redis，每 20 秒延迟写入一次数据库。即使瞬间停止播放，进度误差 < 15 秒，DB 写压力降低约 40%

**3. 签到模块重构**
- 采用 **Redis Bitmap** 重构签到模块，按月生成独立 key（userId + yyyyMM），通过位运算统计连续签到天数。存储空间相比传统数据库方案节省约 80%，支撑万级 DAU 的签到场景

**4. 消息异步解耦**
- 通过 RabbitMQ 对点赞、评论等操作进行异步解耦，将业务处理与统计更新分离，显著提升系统吞吐量

**5. 实时积分排行榜**
- 基于 **Redis ZSet** 实现实时积分排行榜，支持万级用户的实时排名查询（reverseRangeWithScores）。当前赛季实时查询 Redis，历史赛季通过 **XXL-Job 分片任务**按赛季持久化至 MySQL 动态分表（points_board_{season}），通过 MyBatis-Plus 动态表名实现，解决单表性能瓶颈

**6. AI 智能助手集成**
- 参与 AI 智能助手模块开发，集成 **Spring AI + DashScope（通义千问）大模型**
- 实现多种智能体工作流：**增强型智能体**（RAG + 对话记忆）和**路由工作流智能体**（意图识别 + 分发到子智能体）
- 基于 **ElasticSearch 向量库**实现 RAG 检索增强生成，将课程知识库向量化存储，大模型回答时检索最相关的 Top-5 内容，有效减少幻觉
- 实现 **Function Calling**（课程查询、预下单）工具调用
- 支持 **SSE 流式输出**，实现打字机效果，并支持用户手动中断
